# 21：无人机实体模型与视角联动

## 本轮修复

- 多机演示现在默认启用，初始为本机加 4 架独立停机位无人机；仍可用 `?fleet=off`
  进入轻量单机排障模式。
- Cesium 正常作业距离内只显示 glTF 四旋翼实体，放大实体最小像素尺寸并强化选中轮廓；
  点标记仅保留为 2.5 千米以外的降级显示。
- 点击机群列表、3D 无人机实体或态势窗口中的 2D 地图标记，都会更新同一个
  `selectedDroneId`。
- 切换无人机后，3D 视角自动聚焦并进入跟随；第一人称、俯视和全览仍可手动切换。
- 态势窗口切换无人机时自动从“全机总览”进入“选中机”，地图中心、高度缩放和航向同步
  跟随目标；用户仍可再次点击“全部无人机”查看全局。
- 演示模式的起飞、停止和降落按钮现在作用于当前选中的远端无人机，执行后保持相机跟随。
- 3D 场景模型点击会派发机群选择事件，由 Vue 状态层完成 HUD、相机和 2D 地图联动。

## 验证

- `npm run test:fleet`：10 项通过。
- `npm run build`：通过。
- `/models/fleet-drone.gltf` 由 Vite 静态服务直接提供，不需要额外模型服务器。
