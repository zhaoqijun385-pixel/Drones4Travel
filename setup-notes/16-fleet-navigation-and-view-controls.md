# Part 16 — 多机导航与自由视角修正

日期：2026-08-05

## 本轮解决的问题

1. 无人机数量较多时难以查找和切换。
2. 切换无人机时 3D 相机瞬移，且手动视角会被持续抢回。
3. 2D 态势图只容易看到当前无人机，无法稳定查看全机位置。
4. 缺少“某机前往另一架机”和“一键集合”操作。

## 完成内容

### 机群工作台

- 增加按名称、编号和状态搜索。
- 每架无人机增加独立定位按钮。
- 切换“操作对象”和切换“观察视角”已解耦。
- 新增来源无人机、目标无人机和“前往”快捷指令。
- 新增“一键集合”，默认以本机位置为集合锚点。

### 3D 相机

- `自由`：Cesium 相机完全交给鼠标/触控操作，不跟随任何飞机。
- `跟随`：从后上方平滑跟随选中机。
- `俯视`：从选中机正上方观察。
- `全览`：根据全机包围范围自动取景。
- 跟随与俯视模式支持 8–160 米距离调节。
- 普通“选择无人机”不再强制瞬移相机；只有定位或视角按钮会移动相机。

### 2D 态势图

- 全部无人机（包括当前选中机）都进入同一个 Marker 管理层。
- 选中机使用更大的描边和更高层级显示。
- 默认“全部无人机”模式自动适配全机边界。
- 可切换“全部无人机 / 跟随选中机”。
- 打开态势图时机群工作台自动缩小，避免两个窗口互相遮挡；关闭后恢复原状态。
- 修复本地存储恢复后经纬度没有根据停机位重新计算、导致多机重叠的问题。

### 集合与导航规划

- 单机“前往”会在目标机旁分配安全会合点，而不是占用同一坐标。
- 集合会在本机周围分配间隔至少 6 米的独立停位。
- 集合航线使用各机当前位置到分配停位的短航线，保留动态 3 米避让。
- 新任务开始时会清理旧任务航线，避免路线与状态残留。

浏览器实际验收：

- 21 架无人机可搜索到单架目标。
- 选择远端无人机后默认目标为“我的位置”。
- 自由、跟随、俯视、全览视角按钮可用。
- 跟随距离滑块显示并可调整。
- 2D 图同时生成 21 个可点击无人机标记。
- “前往”后目标机进入起飞/航行状态并显示进度。
- “一键集合”会创建全机集合任务并切换到全览。
- 小窗口下打开 2D 态势图不会再与完整机群工作台重叠。

## 安全边界

“前往”和“一键集合”目前只在演示模式执行。实时无人机仍需经过现有控制权租约、服务端命令白名单和真机安全检查，不能从本地演示规划器直接下发。
