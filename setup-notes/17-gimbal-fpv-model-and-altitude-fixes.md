# Part 17 — 云台、第一人称、3D 机型与高度修正

日期：2026-08-05

## 用户反馈

- 左侧 Gimbal 摇杆没有明显产生左右、上下视角变化。
- 缺少第一人称飞行视角。
- 3D 场景中的无人机全部使用点，不适合正式演示。
- 手动升降、单机前往和集合任务的高度行为不可靠。

## 根因

1. 原云台摇杆把偏航、俯仰、横滚拆成 `Z / Y / X` 三个单轴模式，同一次拖动无法同时控制左右与上下。
2. 多机跟随相机没有读取全局云台姿态。
3. `isOnGround` 错误复用了 8–12 米街景切换门限，导致 1–7 米低空飞行仍被判定为“在地面”；切回平移或转向模式后会被吸回地面。
4. 高度摇杆使用了三倍灵敏度，升降速度最高达到不适合演示的量级。
5. 演示无人机的 `z`（相对高度）与 `alt`（绝对海拔）没有在所有指令路径中同步。
6. 单机“前往”使用公共低空走廊，可能被静止无人机永久阻塞。

## 完成内容

### 云台

- 默认模式改为 `P`（Pan / Tilt）。
- 横向拖动同时控制相机左右观察。
- 纵向拖动同时控制相机上下观察。
- 键盘方向键采用相同的双轴语义。
- 俯仰限制为 `-85°` 至 `45°`，偏航保持在 `-180°` 至 `180°`。
- 保留 `X` 模式作为可选横滚微调。

### 第一人称与其他视角

- 新增 `FPV / 第一人称`。
- 第一人称相机位于选中机机体上方 0.28 米。
- 第一人称读取机体航向以及云台偏航、俯仰、横滚。
- 跟随视角也读取云台偏航和俯仰，云台不再只更新 HUD 数字。
- 第一人称时隐藏当前选中机的外部模型，避免相机穿进模型。

### 3D 无人机表现

- 新增内嵌缓冲区的轻量 glTF 四旋翼机型。
- 近距离显示 3D 机型，远距离自动降级为点。
- 选中机增加白色轮廓。
- 机型按照无人机实时偏航旋转。
- 模型使用无人机颜色进行轻度混色，同时保留机头、机臂、旋翼和相机的结构识别。

### 高度与动作

- 地面接触门限改为 0.2 / 0.45 米滞回，与街景 8–12 米门限彻底分离。
- 手动升降速度降为最大 3 米/秒。
- 高度摇杆不再叠加三倍灵敏度。
- 下降不会穿过已采样的地面。
- 场景表面尚未加载时，不使用错误的 0 米表面进行强制限高。
- 演示机群使用表面海拔作为绝对高度原点，`z` 始终保留为相对高度。
- 演示“上升 / 降落”指令同时更新 `z` 与 `alt`。
- 单机前往改为：垂直升至 4.2 米过渡层 → 水平前往安全会合点 → 下降至 1.1 米。
- 到达后的状态为 `onstation`，不再把悬停中的无人机错误标为“已停机”。
- 集合任务最后下降至 0.12 米停机高度。
