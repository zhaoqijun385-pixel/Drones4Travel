# 22：FPV 起飞与视角切换修复

## 根因

- 远端演示机的起飞曾被实现为直接把相对高度改成 3 米，未经过连续的自动飞行状态。
- 从跟随/俯视切换到 FPV 时，Cesium 相机仍可能保留目标相对坐标系。
- 起飞过程中再次播放面向旧位置的相机飞行动画，导致相机落后后突然跳回实时位置。

## 修复

- 远端演示机恢复为逐帧自动起飞和降落，速度与原本本机自动起降一致，为 8 米/秒。
- 起飞目标读取现有 `takeoffAltitude` 设置，默认 100 米，不再固定跳到 3 米。
- 自动起降不会因切换选中无人机而中断；停止操作会取消自动高度目标并在当前高度保持。
- FPV 每次更新前解除 Cesium 的目标相对坐标系。
- 无人机处于起飞、降落、航行或返航时，视角切换立即绑定实时坐标，不播放指向旧位置的过渡动画。
- 静止无人机的跟随和俯视切换仍保留平滑过渡。
- 重新启用演示模式时重置计时基准，避免停用期间累计的时间造成高度瞬移。

## 验证

- 新增连续 FPV 起飞测试：高度单调上升，速度为 8 米/秒，最终到达 100 米并进入保持。
- 新增连续降落测试：高度逐步下降，最终到达停机高度并进入 `parked`。
- `npm run test:fleet`：12 项通过。
- `npm run build`：通过。
