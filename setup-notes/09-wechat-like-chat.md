# 类微信聊天体验优化记录

## 本次完成

- 保留现有 Matrix 私聊、群组、输入中状态和已读回执链路，不重复引入新的消息服务。
- 会话列表增加本地搜索、未读数量角标和总未读提示；未读数量直接读取 Matrix 房间通知计数。
- 通讯录从原来的占位页改为可搜索联系人列表，支持点击联系人直接创建或打开私聊。
- 增加联系人卡片视图，为后续扩展备注、在线状态、无人机权限和群组操作预留位置。
- 展厅入口改为功能说明页，明确媒体附件后续使用 Matrix 媒体缓存接入，避免当前按钮看似可用但实际没有上传链路。

## 性能处理

- 通讯录使用 `sessionStorage` 缓存，缓存有效期为 5 分钟；缓存过期时先展示旧数据，再后台刷新。
- 同一时间只允许一个通讯录请求，避免重复点击和多个组件同时触发重复网络请求。
- 房间摘要缓存最近消息预览，避免每次同步都扫描整个房间时间线。
- 单次渲染最多保留最近 240 条文本消息，降低长会话 DOM 数量；Matrix 历史数据仍保留在 SDK 中，可在后续补分页加载。
- `matrix-js-sdk` 改为聊天页首次需要时动态加载，减少控制台首页首次下载和解析成本。
- 用户退出或切换账户时清理 Matrix 凭据、通讯录缓存和房间摘要，避免跨账户残留。

## 当前边界

- 图片、视频、文件、语音和消息撤回尚未接入真实 Matrix media API；入口已保留，后续应配合上传进度、缩略图缓存和失败重试一起实现。
