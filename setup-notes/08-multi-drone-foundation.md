# 多无人机 3D 基础能力（twin 分支）

日期：2026-08-05

## 已完成

- 在现有 Vue/Cesium 架构上增加可选机群工作台，不改默认单机页面路径。
- 使用 `?fleet=demo` 生成 20 架本地模拟无人机，支持选中、跟随、名称、电量、在线状态和距离展示。
- 左侧 Dock 增加“开启/关闭多机模式”按钮，可在不刷新页面的情况下切换状态；`?fleet=demo` 仍可作为直接进入演示模式的调试入口。
- Cesium 使用缓存的 Point/Label Entity 复用位置对象；机群更新限制为 20 Hz，标签距离和无人机距离分别裁剪，减少移动端更新压力。
- 增加 FPS、对象数和可见对象数统计，便于后续阶段建立性能对比。

## OpenClaw 联动边界

- 复用现有 OpenClaw Gateway WebSocket 客户端。
- 机群工作台只在 `?fleet=demo` 模式自动连接 OpenClaw。
- “同步到 OpenClaw”是显式、只读的态势同步，发送房间、无人机位置、电量、选中机和共享目标上下文。
- 不新增飞控旁路；起飞、降落、移动和急停仍走现有 Crazyflie 命令校验链路。

## 验证

- `cd client && npm run build`：通过。
- `node --check`：新增机群模块、OpenClaw 模块和 Cesium 模块通过。
- `git diff --check`：通过。
- 浏览器验证：`?fleet=demo` 显示本机加 20 架模拟机，点位可见数正常，选择和跟随按钮可用；无查询参数时机群面板隐藏。
- 首次浏览器检查发现 Cesium `fromDegrees` 的 result 参数位置错误，已修正为 `Ellipsoid.WGS84 + result`，修复后不再出现机群更新异常。
- 浏览器验证按钮切换：默认显示“开启多机模式”，点击后出现机群面板；再次点击“关闭多机模式”后面板隐藏并清理 Cesium 点位，切换过程无新增运行时错误。
- 增加 OpenClaw 飞行助手浮窗：可打开聊天、选择目标机、使用悬停/前进/左移/上升/降落快捷指令，并在执行前显示二次确认卡。
- 当前快捷指令只改变模拟机状态；真实无人机指令必须等待多机控制权租约和 DroneSession 服务完成，不能从浮窗绕过现有命令校验。
- 当前本机未监听 OpenClaw `127.0.0.1:18789`，因此 OpenClaw 状态显示离线；网关启动后可通过“同步到 OpenClaw”发送只读态势上下文。

## HUD 优化

- 将原有单块文本遥测条改为状态栏 + 指标卡布局，保留仿真和实机两套原始数据字段。
- 实机模式突出链路状态、位置三轴、姿态三轴和电压；仿真模式保留飞行、相机、位置、方向和云台信息，数值使用等宽对齐和空值保护。
- AerialView 打开 OpenClaw 浮窗时，HUD 自动避让右下区域；移动端改为上下分区，避免两个固定浮层重叠或横向溢出。
- 使用 `contain: layout paint`、无额外刷新定时器和 reduced-motion 样式，降低 HUD 对 3D 场景渲染的影响。

## 左上角无人机态势窗口

- 左侧 Dock 增加可选的无人机态势窗口，默认关闭，不改变原有 3D 画面布局。
- 窗口支持“2D 位置 / 实时画面”切换：2D 位置复用现有 Google Map 组件并以选中机为中心，实时画面复用现有 MediaMTX WHEP 播放器。
- 窗口内可选择当前机群目标机，并与 OpenClaw 的目标选择保持一致；未开启多机模式时显示本机位置。
- 视频流按无人机 `streamId` 或 `droneId` 查找，找不到专属流时回退到主流 `crazyflie-drone`；当前 demo 无专属多流映射，不伪造视频来源。
- 2D 地图位置刷新限制为 5 Hz，避免高频机群遥测直接驱动 Google Maps 重排。
- 地图组件采用按需挂载、关闭后保留实例；视频 WHEP 连接关闭后保活 30 秒，立即解绑隐藏视频元素，避免重复握手和后台解码。
- MediaMTX 流目录使用 `localStorage` 缓存：10 分钟内直接命中，最长 24 小时作为弱网回退；后台配置请求 3 秒超时，不阻塞界面显示。

## 多机流畅性修正

- 多机模式不再自动连接或自动重试 OpenClaw，只有打开飞行助手并主动连接时才建立网关连接，避免网关未启动时持续“转圈”。
- Cesium 相机同步改为仅在姿态变化时更新，且上限 30 Hz；机群实体按状态序号签名跳过重复写入。
- 本机机群状态只有位置或航向发生变化时才递增序号，避免主循环重复制造响应式对象和 Cesium 更新。
- `?fleet=demo` 的初始 3D 瓦片等待上限改为 12 秒，默认单机路径仍保留 45 秒完整渲染等待。
