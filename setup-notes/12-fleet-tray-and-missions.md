# 机群托盘、固定停机位与演示任务

日期：2026-08-05

## 已完成

- 新增默认可见、可最小化的机群托盘；最小化状态保存在浏览器本地。
- 默认仍为单架本机无人机，不自动创建 20 架模拟机。
- 支持新增模拟/真实无人机档案、切换选中机和二次确认删除。
- 无人机档案持久化到浏览器本地；删除本机无人机被明确禁止。
- 模拟无人机使用固定网格停机位。没有任务时不更新位置，也不再围绕中心绕圈。
- `?fleet=demo` 仍保留为 20 机负载入口，不改变普通入口的单机默认值。

## 演示任务

- 新增“分区巡检”“交叉换位”“全部返航”三个预设。
- 每架无人机按当前位置选择距离较短的未占用目标。
- 任务使用低空起飞、前往目标、短暂停留、返航和降落状态机。
- 当前安全版本采用低空走廊独占：上一架完成并返航后，下一架才放行；同时保留小幅高度分层。该策略牺牲吞吐量，但自动化验证能够稳定保持至少 3 米间距。
- 每架无人机保留自己的路线、目标、阶段和进度；路线同时传递到 Cesium 3D 和 Google 2D 地图。
- 停止任务会保持当前位置，不伪造已经返航或已经降落。

## 界面

- 飞行甲板采用统一深海军蓝、信号青、安全绿、警示黄和危险红。
- 任务航段条是唯一持续变化的强调元素。
- FPS、对象数、可见数和 Agent 状态移入折叠诊断区。
- 键盘焦点和 reduced-motion 已处理。

## 验证

- `node --check`：任务规划器和机群状态模块通过。
- `npm run build`：通过。
- 本阶段仅执行浏览器仿真代码，没有连接 Radio 或实体无人机。
