# 3D、2D 地图与 HUD 性能优化

日期：2026-08-05

## 3D

- Google Photorealistic 3D Tiles 初始使用较宽松的屏幕空间误差，优先得到可操作粗场景。
- 普通入口的精细瓦片等待上限由 45 秒改为 8 秒，20 机演示入口为 6 秒。
- 首屏放行 10 秒后自动恢复平衡画质，精细瓦片继续在后台加载。
- 数据源切换等待上限由 30 秒改为 10 秒。
- 启用移动期间请求裁剪和动态屏幕空间误差。
- Cesium、Google Maps、Google 静态资源和瓦片域名增加预连接或 DNS 预解析。

## 2D 地图

- Google Maps JavaScript API 继续复用启动页已有的预加载。
- 无人机态势组件在浏览器空闲时预挂载真实地图实例。
- 关闭窗口时地图移到屏幕外并保持实例，不再销毁和重复握手。
- 再次显示时触发地图 resize、位置和缩放同步。
- 低空机群优先显示本地 `z` 高度；Google Map 自己负责将过低高度限制为可用缩放级别。

## HUD

- 常驻字段收敛为选中无人机、状态、高度、电量、控制权和任务航段。
- 经纬度、三轴姿态、相机和 FPS 不再挤占主 HUD；FPS 和对象数进入机群托盘诊断区。
- HUD 和机群托盘统一为飞行甲板视觉语言。
- 任务航段条展示当前目标和任务进度。
- 桌面、窄屏、OpenClaw 避让和 reduced-motion 均保留。

## 浏览器验证

- 本地 Vite 页面完成真实浏览器检查。
- 默认显示一架本机无人机和展开的机群托盘。
- 新增 `Surveyor A` 后立即选中，并显示任务按钮。
- 分区巡检进入 `En route`，HUD 显示相对高度 `0.90 m` 和实时进度。
- 2D 态势窗口从点击到窗口可见约 318 ms；地图实例已在后台预热。
- 二次确认删除和窗口最小化/恢复通过，最后清理测试无人机并恢复单机。
- 浏览器控制台无 error。现有 Google Marker 弃用 warning 仍存在，后续迁移 Advanced Marker 时需要为 Google Map 配置 map ID。
- 测试后已停止临时 Vite，5173 未留监听。
